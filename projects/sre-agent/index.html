An experimental but production-adjacent SRE agent that closes the gap between alert fire and human context.

Architecture

FastAPI backend with a Streamlit operator UI, a Redis-backed state store for in-flight incident context, and an MCP sidecar exposing Grafana/Loki/Kubernetes as callable tools to the Claude-backed reasoning loop. Azure AD handles RBAC on who can approve a remediation action. A validator gate sits between “the agent proposes a remediation” and “the remediation executes” — every action has to clear that gate before it touches the cluster.

Trade-offs

Validator gate vs. full autonomy — kept a human-approvable gate in front of any state-changing remediation, trading some of the “before a human wakes up” promise for a hard guardrail against a bad LLM decision touching production.
